# SneakDup — Shoe Retail System

## Project overview
SneakDup is a shoe catalog and retail system. Customers can browse shoes and product variants, while staff can use tools for point of sale, inventory management, and sales analytics.

## Live demo
[Open SneakDup](https://sneakdup-eight.vercel.app/)

## Main features
- Shoe catalog and product details
- Product variants such as size and color
- Staff tools for point of sale and inventory
- Sales analytics for store operations

## My role
I developed SneakDup, working on the customer-facing catalog and staff workflows.

## Database quality demonstration
My portfolio includes a visual walkthrough of SQL checks for:
- Repeated product, size, and color combinations
- Missing product-variant details
- Stock values that need review

The walkthrough uses fictional sample rows. It is an illustrative demonstration and does not connect to or change SneakDup’s live database.

## Technologies
HTML, CSS, JavaScript, PHP, and MySQL.
